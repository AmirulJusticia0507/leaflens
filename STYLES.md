
# Design System & UI Styles

## Theme Palette (Botanical Dark / Light)

- **Primary Green:** `#16A34A` (Tailwind `green-600`) - Status Daun Sehat
- **Accent Emerald:** `#059669` (Tailwind `emerald-600`) - Accent Buttons
- **Warning Yellow:** `#EAB308` (Tailwind `yellow-500`) - Indikasi Hama / Kering
- **Alert Red:** `#DC2626` (Tailwind `red-600`) - Penyakit Parah / Busuk
- **Background Dark:** `#0F172A` (Tailwind `slate-900`)
- **Background Light:** `#F8FAFC` (Tailwind `slate-50`)

## Layout Standards

- **Scan Dashboard:** Tampilan kamera responsif dengan *overlay guide* berbentuk lingkaran/kotak tempat meletakkan daun.
- **Result Card:** Menampilkan foto daun, nama ilmiah (italics), nama lokal, tingkat keyakinan (confidence rating), dan saran perawatan.
