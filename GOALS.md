
# Project Roadmap & Goals

- [ ] Konfigurasi PNPM Workspace & setup Next.js + FastAPI.
- [ ] Integrasi FastAPI dengan Ollama API lokal menggunakan model DeepSeek.
- [ ] Buat parser response Ollama untuk memastikan output berbentuk JSON terstruktur.

## Milestone 2: Core Leaf Scanning Feature

- [ ] Buat UI upload foto / kamera interaktif di Next.js.

- [ ] Tampilkan hasil deteksi jenis daun dan diagnosa kesehatan di UI.

## Milestone 3: History & Growth Monitoring

- [ ] Buat dashboard timeline pemantauan perkembangan daun dari waktu ke waktu.
- [ ] Grafik indikator kesehatan tanaman berdasarkan histori scan bulanan.
